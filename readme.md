# Intro
For now, this is just a small game inspired by Breakout/Arkanoid. I'll keep working on it and adding some new features, more on that below.

## Controls
- A: Move left
- D: Move right
- Space: Start
- Left Ctrl (hold): Speed up time

## Installation
- Download Godot from [godotengine.org](https://godotengine.org/)
- Clone this repository
- Import the project into Godot and run it
- Alternatively, executables for Windows, Linux, and Android can be downloaded on itch.io (coming soon).
